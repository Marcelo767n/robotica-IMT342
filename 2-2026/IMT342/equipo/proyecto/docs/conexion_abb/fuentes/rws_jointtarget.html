Get Joint target

URL

/rw/motionsystem/mechunits/{mechunit}/jointtarget

Method

GET

URL Params

  • ignore=1 if present will get joint target always.

See Common URL parameters

Data Params

None

Success Response

HTTP_OK(200), see HTTP Status codes

Sample Call

Note

Not supported in boot server.
